| 版本段 | engines.node | v26.10.0 是否满足 |
|---|---|---|
| 10.6 / 10.7 / 10.8 / 10.9 | `>=24.22.1 <25 \|\| >=26.12.1` | ❌（10-31 被卡在这） |

## release notes 定性（上游 CHANGELOG/<version>.md）
- **11.1 / 11.2 / 11.3 / 11.4 / 11.6**：均为 "patch release with no new features"，价值在安全与可靠性修复。
- **11.3 = Security release**：修 worker transfer 空指纹证书校验、sandbox image preview 越界、凭据暴露。
- **11.5 = 大版本**（9,954 PRs / 746 contributors）：standalone build（可脱离 Node/Bun 跑 Gateway）、实验性 AOT 编译（跑 CommonJS/TS 插件、**Node Code Mode cells**、continuations）、Code Mode 解释器、QA Lab 表达式与 lambda 走解释器；主打流式输出少卡顿、断线后聊天恢复、跨设备停任务。
- 门槛守卫仍在：**11.1「Checks the target Node requirement before staging Git updates」**（10.7 引入的「版本不满足就停下并保留当前 Gateway」延续）→ 升级不会升到半残。

## 与本机栈相关的条目
- **Feishu**：11.x 修了流式文本跨 tool call 丢失、action card 格式错、block streaming 关闭时 caption+附件丢失、Doctor 恢复备份漏提交 → 本机 `send-backup-log-feishu.py` + 日报推送受益。
- **WeChat/weixin 通道**：11.x notes **零命中** → 内置 `openclaw-weixin` 无回归风险。
- **thinking / adaptive**：11.x 全是 Claude 侧改动（切模型丢 thinking、thinking picker、compaction 报错更清楚）→ 本机 **M3/M3.1-Flash 强制 `thinking=adaptive` 的 per-model 参数覆盖保留不动**，上游没有接管这条。
- **minimax / ollama / litellm / openrouter / siliconflow**：11.x notes **零命中** → provider 链与 fallback 链不受影响。
- **记忆/配置恢复**：11.4 修「配置恢复在大格式化后丢失已接受编辑」+「Doctor 合并 legacy memory 截断 MEMORY.md」+「恢复副本被损坏」→ 直接命中本机 MEMORY.md 维护路径（11-01 那次 read-modify-write 截断事故的正面对策）。
- **Doctor 语义变更**：11.1 起 Doctor 失败/无效/迁移挂起时**返回非零退出码** → 本机 crontab 无 doctor 调用，无影响；`doctor --json` 脚本需注意。
- **Standalone / AOT**：11.5 新形态，本机 systemd unit 仍走 `node dist/index.js`，**不需要**改造；若想摆脱「两处 node」耦合可后续评估 standalone build。

## ⚠️ 升级前必须处理的存量问题（与升级无关，但会被升级放大）
1. **openclaw-weixin 插件已 broken**（10-19 更新时就报）：`ERR_PACKAGE_PATH_NOT_EXPORTED: Package subpath './plugin-sdk/infra-runtime' is not defined by "exports"`。当前 core 2026.10.5 的 package.json exports 共 344 个 plugin-sdk 子路径，**不含 `infra-runtime`**。npm 上 `@tencent-weixin/openclaw-weixin` 最新就是 2.4.10（= 本机装的版本）→ 升 core 后仍需 `openclaw plugins update openclaw-weixin`；若 11.6 已导出 `infra-runtime` 则自动恢复，否则要等上游插件发新版。
2. **memory-lancedb-pro 是 operator-managed 本机副本**（`~/.openclaw/workspace/plugins/memory-lancedb-pro`，v1.1.0-beta.11）→ **不会被自动更新**，升级后要自己核对与 11.6 的兼容性。
3. **default-account-routing 警告**：`channels.openclaw-weixin.accounts.default` 缺失、账号 `727ad0599b5f-im-bot` 没有 account-scoped binding → 需要 `bindings[].match.accountId` 或加 `accounts.default`。
4. **C: 盘只剩 11G（98%）**：升级安装目标在 WSL 的 `/dev/sdd`（778G 可用），不受影响；但 C: 满会拖垮 npm/Windows 侧其它动作，建议单独治理。
