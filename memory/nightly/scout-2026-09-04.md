## Key Research Findings

### LLM Judge Reliability Crisis (2609.04198)
LLM judges on shared endpoints are NOT frozen instruments. Same model name, same request → Spearman 0.400 same-window, 0.78 next-day. Far below required thresholds (0.90/0.99). Proposed: snapshot-identity ladder + design rules.

**Impact:** Benchmark credibility at risk. Evaluation methodology needs redesign.

### NLIP: New Agent Protocol Standard
Natural Language Interaction Protocol standardized by **Ecma International**. Cross-company/uni effort. Provides semantic message envelope over HTTP/WebSocket/AMQP. Direct MCP competitor.

**Impact:** Agent interoperability standard landscape heating up.

### GRPO Spurious Advantage → SIGNBALANCE (2609.04063)
GRPO assigns high advantage to guess-like rollouts that happen to land correct answer. SIGNBALANCE fixes via sign preservation + global scale + stop-gradient rescaling.

**Impact:** Better RL training for math agents and search agents.

### Gated DeltaNet Survives 4-bit Quantization (2609.04098)
Minima recipe: NVFP4 W4A4 on all 496 linear layers of Qwen3.8-27B. Matches BF16, 17.5 GiB, +14-19% prefill speed. Recurrent half of hybrid LLM is the easy half to quantize.

**Impact:** Edge deployment of hybrid LLMs becomes more practical.

### CAPA: Meeting Agent Situational Awareness (2609.03923)
Collaborative Agent Predictive Architecture: Perceiver-Predictor-Controller-Generator-Recalibrator. Silence rate 51.4% → 2.5% on AMI corpus. Hallucination 0.6%.

**Impact:** Multi-agent meeting participation becomes viable.

### STAIR: Structure-Aware Retrieval (2609.03874)
Uses Table of Contents to guide retrieval. Recall@1: 82.6% vs DSI 76.9% vs BM25 59.5%. Hallucination <0.05%. SearchTome benchmark released.

**Impact:** RAG "lost in middle" problem partially solved.

### Proactive Service Agents Survey (2609.03727)
Unified framework for agents that infer service opportunities from incomplete signals. Four actions: Silent/Ask/Assist/Act. Partially observable decision process.

### Anthropic MHS (Model Hardware Standard)
Research preview opened 2026-08-27. Shared spec for AI agents to safely operate physical devices. First group: scientific labs + advanced manufacturers.

**Significance:** AI safety meets robotics; potential next MCP-level ecosystem.
