### 4 个核心保护（下次升级必加）

1. **`Restart=no` override**（drop-in 文件 `~/.config/systemd/user/openclaw-gateway.service.d/upgrade-override.conf`）—— 避免 drain 超时后无限重启循环
2. **`OOMScoreAdjust=-1000`** —— 保护升级期间所有 exec 命令不被 OOM killer 杀
3. **`--max-old-space-size=4096`** —— 让 V8 GC 更早触发，泄漏提前暴露
4. **手动 dry-start**（Step 5 不接 systemd）—— 先确认能起来再上 systemd，避免启动失败

### 关键经验教训

- **`sudo systemctl --user` 在 WSL2 走不通** → 用 `systemctl --user`（不带 sudo）。sudo 不传 DBus session
- **CLI 版本 ≠ gateway 版本** —— `openclaw --version` 是 npm-global 版本，但 systemd ExecStart 指向 NVM。**升级前必查 `grep ExecStart unit`**
- **`cp -a` 大目录（>10G）必须 `setsid ... </dev/null >log 2>&1 & disown`** —— exec 默认 5min timeout 会 SIGKILL cp，留下半截快照
- **`openclaw backup create` 在不稳定 gateway 下会 hang** —— 用 `cp -a` 快照代替
- **doctor 关键判断点：** 无 `schema version mismatch` + `agent database integrity gate` 通过 = 升级成功。其他 warning 都是预存的
