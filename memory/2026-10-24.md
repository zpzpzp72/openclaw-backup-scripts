**教训**：
- 报错里带 provider 名字 ≠ provider 故障。`configured fallbacks disabled by user model override` 说明 fallback 被会话级 modelOverride 屏蔽，真实错误在 `rawError` 里。
- session 级 `modelOverride` 会让配置里的 fallback 链失效 → 排查 fallback 故障先看 session_nodes.entry_json 的 modelOverride。
- 改 primary/fallback 链时必须同时验证 thinking 兼容性，否则新 primary 立刻踩载荷不兼容。
- `openclaw agent exec` 的 message 是**位置参数**（`--message` 是 `openclaw agent` 的选项）；`openclaw agent --session-key ...` 会报 "Gateway agent from agent exec would lose inter-session attribution"（CLI 归因保护，非模型错误）。
- 探测脚本写文件再执行，别用长 heredoc；`openclaw agent exec` 单次约 30-90s，前台串行跑，后台进程会被 exec 会话回收。
