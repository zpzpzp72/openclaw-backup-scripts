**结论：10.6 起连续三个版本（10.6 / 10.8 / 10.9）都是安全发布，且 10.6+ 强制 Node ≥26.12.1。**
本机 v26.10.0 不满足 → 必须先升 Node，再升 OpenClaw。
10.7 还新增了 updater 守卫：「Package updates now stop before staging a release that requires a newer Node than the Gateway service uses」→ 版本不匹配时更新会**主动停下并保留当前 Gateway 运行**，不会半途搞坏。

**内容层面：10.6 与 10.7 均声明「patch release with no new features」**，10.8 / 10.9 同样。价值全在安全与可靠性修复。

### 与本机环境直接相关的修复
- **fallback/retry 时间预算**（10.6 #155801/#164808/#170495）：retry 与 fallback 现在各自获得独立时间额度，不再因准备阶段吃掉额度而几乎没时间。
- **限流重试保留 prompt cache 历史**（10.6 #177050）：429 重试不丢历史 → MiniMax 缓存命中不再白付 input 价。
- **Doctor 不再重置你手动设过的 runtime 选项**（10.6）：直接关系会话级 modelOverride pin 会不会被 Doctor 清掉。
- **插件/通道部分加载失败时明确报出，并让已加载的继续工作**（10.6）：对应 weixin 插件 2.4.9 加载失败那类问题。
- **Memory Wiki 大 vault status 更快 + dreaming 历史清理不拖慢 reload + embedding provider 全挂时 Doctor 说明原因**（10.6）：对应 memory-lancedb-pro + siliconflow embedding。
- **truncated 配置不再覆盖健康恢复副本**（10.7 #152565）：openclaw.json 被意外截断时 Doctor 仍可恢复。
- **恢复备份保留受支持的旧 exec approval 规则**（10.7 #181465），不再一律 deny-all。
- **中断/压缩后的 agent turn 保留正在处理的请求与更完整的工具结果**（10.7）：对应本机多次出现的 turn 被中断。
- **Managed Claude CLI turn 改用 OpenClaw 工具面**（10.7 #172026）：升级后不再加载 Claude 用户设置 / CLAUDE.md / 规则 / auto-memory / 用户 hooks / Chrome / Claude 专属 MCP，且旧会话首个 turn 会开全新 native Claude session —— **破坏性行为变更**。
- **10.9**：修 vulnerable dependencies + 凭据处理 + workspace 限制（工具跑错项目目录）。

### 执行方式
升级由 owner 在聊天里发 `/update`（Gateway 自行协调重启与完成通知）；不要用 exec 跑 openclaw update / npm i -g / 停启 gateway service。Node 升级需 owner 侧先做。
