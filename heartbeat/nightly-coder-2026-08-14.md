## 7. Learned Pitfalls (来自 ERRORS.md)

### git fatal errors (non-critical)
- **现象**: 嵌入式 runs 从非 git 子目录执行 git 操作
- **根因**: workspace 本身是有效 git repo（origin = openclaw-backup-scripts），子 agent 在 plugins/agents/ 等子目录的 git 上下文中操作时偶发
- **预防**: cron 脚本加 `cd /home/zhiping/.openclaw/workspace &&` 前缀

### npm outdated 输出截断
- **现象**: `npm outdated` 只输出表头无数据行
- **根因**: 命令在输出完整前被捕获
