### 3. LTL to LTLf+ Translation (2608.02454)
**领域:** Formal Methods · Logic · AI Planning
线性时序逻辑 LTL 是 AI 中指定时序目标最广泛语言（反应合成、 MDP 规划、 RL）。传统方法将 LTL 翻译为无限词非确定性自动机后确定化，理论上困难实践中更难。LTLf+ 是可表达相同内容但基于有限词自动机的逻辑。本文给出首个 LTL→LTLf+ 翻译，使 LTLf+ 技术可用于所有现有 LTL 问题。
**意义:** 理论上完整（双指数复杂度与现有 pipeline 相同），实际工程上更可操作。

### 4. Shortcut Hacking in LLM Reasoning (2608.02442)
**领域:** LLM Evaluation · Reasoning · Benchmark Integrity
识别 Solution Hacking：LLM 通过无效捷径（数值搜索、枚举、猜测、答案优先验证）得到正确答案而非有效推导。影响随难度急剧上升：普通问题 2.2% → 奥赛水平 28.3% → HLE 37.4%。44.1% 的"正确答案"实为 hacking。前沿模型 8.2%-44.1% 的正确答案被识别为 hacking。
**意义:** 揭示仅评估最终答案严重高估前沿 LLM 科学推理能力，需要 anti-hacking 策略。

### 5. Parallel Refinement for Diffusion Drafters — xPress (2608.02438)
**领域:** LLM Inference · Speculative Decoding · Diffusion
dFlash 等 block-diffusion drafters 单次前向传递生成整块草稿，但草稿是 per-position 边缘分布而非联合分布，导致早期拒绝和接受长度受限。xPress 通过并行精炼恢复扩散草稿器的因果性。
**意义:** 提升 speculation decoding 效率的底层改进，降低 LLM 推理延迟。

### 6. MonitrLLM: Community-Centered LLM Evaluation (2608.02409)
**领域:** LLM Evaluation · User Feedback
基准测试评估受控任务，对话语料库捕获自然使用但不记录用户反馈，反馈机制记录满意度但不关联任务目的。三者之间存在空白。MonitrLLM 开源基础设施将完整对话转录 + 用户报告任务意图 + 结果评估作为三个主要评估信号。两周试点（26 名大学生，206 份评估报告）：平均满意度 4.19/5，但高满意度 ≠ 任务成功。
**意义:** 揭示满意度与任务成功率的脱节，评估需要连接对话轨迹与真实任务结果。

### 7. CoPES: Cooperative Coevolution for Agentic LLM Post-Training (2608.02391)
**领域:** LLM Post-Training · Agentic AI · Evolution Strategies
工具调用 LLM agent 产生长多轮轨迹，梯度后训练内存密集。Evolution Strategies 可无反向传播进行内存高效的全参数后训练，但资源受限（少GPU）时 ES 的高 GPU 小时需求导致训练时间不可接受。CoPES 将参数空间分解为低维子空间进行合作协同进化。在 Qwen3.5-4B 数学任务上，在 GRPO 最佳验证 checkpoint 相同 GPU 小时预算下，CoPES 恢复 GRPO 92% 验证精度增益（ES 仅 67%）。
**意义:** 资源受限环境下的 agentic LLM 后训练新范式，合作协同进化显著提升效率。

### 8. Do World Action Models Need Deep Action Modules? — Faster-WAM (2608.02365)
**领域:** Robotics · World Action Models · Efficiency
World Action Models (WAMs) 耦合机器人动作预测与视频世界模型。现有 WAM 共享 backbone 和 MoT 设计将 action module 深度绑定到 video backbone，导致推理延迟高。提出 DoT (Dock of Transformer)：将预训练视频 Transformer 作为表征中心，通过 docking 接口连接轻量输出头。Faster-WAM 将单层 action head 停靠到 30 层 video backbone。
**意义:** 机器人动作模型轻量化重要进展，推理效率与性能解耦。

### 9. KC-Agent: Dual-Process Cognitive Architecture for ML Model Improvement (2608.02351)
**领域:** Cognitive Architectures · MLOps · AI Systems
生产环境中数据漂移要求持续模型更新。KC-Agent 双重过程认知架构：System 1 快速模式识别 + System 2 审慎增量更新。通过结构化记忆系统让 System 1 复用 System 2 发现的成功解决方案，实现高效基于模式的响应。NASA 涡轮风扇真实数据上准确率 76.8%，执行时间 13.2s。
**意义:** 认知架构应用于生产级 ML 自动改进，系统 1/2 分离是关键设计。

### 10. Curling Tactical Decision-Making via DRL (2608.02379)
**领域:** Reinforcement Learning · Game AI · Tactical Planning
冰壶"冰上象棋"，战术决策复杂但 ML 研究不足。挑战：连续状态/动作空间、技能变异随机性、动作执行小扰动高度敏感状态转移。提出 DDPG actor-critic 适应有限视野结构，完全自监督学习无需人工标注数据。
