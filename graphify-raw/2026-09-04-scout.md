## LLM Judge Reliability Crisis

**Paper:** [2609.04198] Clean Engineering, Unstable Measurement: A Preregistered Reliability Failure of Black-Box LLM Observers on Shared Endpoints

Language-model judges gate training data, score generations, and drive leaderboards. The judge is a measurement instrument resting on one assumption: the same request, sent to the same model name, reads the same tomorrow.

**Audit results across 52,988 requests:**
- Same-window repeat rankings: Spearman 0.400 (required: 0.90)
- Byte-identical next-day replays: 0.78 (required: 0.99)

**Three mechanisms explain the gap:**
1. Label-to-meaning mapping biased readouts as strongly as the signal
2. Candidate gaps seven orders of magnitude below the instrument's own noise floor
3. Byte-identical inputs returning different rankings

**Proposed solution:** Three-level snapshot-identity ladder, eight design rules, reporting checklist. On a shared endpoint, a model name is not a frozen instrument.

**Impact:** LLM benchmark reliability, AI evaluation methodology, model leaderboard credibility.

## GRPO Spurious Advantage

**Paper:** [2609.04063] Spurious Advantage Hidden in GRPO

Group Relative Policy Optimization (GRPO) is widely studied for RL with verifiable rewards. Its advantage estimator assigns each rollout a magnitude from within-group reward statistics.

**Problem:** In the common case, this magnitude rewards rollouts that reach the correct answer through reasoning. But a rollout may land on the answer by guessing — and the formula still assigns a high magnitude. This is the spurious advantage.

**Three cases where this misleads policy toward guess-like behaviors:**
1. Bounded-answer tasks with small candidate set
2. Open-answer sets hosting bounded sub-cases
3. Search agents whose budget opens many paths to the same answer

**SIGNBALANCE solution:**
- Keeps verifier sign
- Uses global scale
- Restores zero-mean balance via stop-gradient per-class rescaling

Results: matches GRPO on open-answer math; improves on bounded-answer math and search agents.

**Impact:** RL for LLMs, agent training methods, GRPO improvement.

## Gated DeltaNet 4-bit Quantization

**Paper:** [2609.04098] Why Gated DeltaNet Survives 4-Bit Quantization: NVFP4 W4A4 for the Recurrent Half of a Hybrid 27B LLM

Hybrid LLMs pair softmax attention with linear-attention layers (Gated DeltaNet / GDN). GDN recurrent state summarizes context in fixed size.

**Early community 4-bit quantizations of Qwen3.8-27B left GDN block in 8- or 16-bit precision** — on the intuition that errors in recurrence accumulate over long contexts. This intuition was wrong.

**Minima recipe (NVFP4 W4A4 on all 496 linear layers, GDN included):**
- Matches BF16 within seed noise (5-task average -0.52)
- Smallest: 17.5 GiB
- Fastest prefill: +14-19%
- 32K perplexity gap shrinks with position

**Four-part mechanism:**
1. NVFP4 block scaling localizes extreme outliers, equalizing activation error across layer roles
2. Gate projections (softplus/exponential and sigmoid) are least sensitive — compress ~11% GEMM error to ~2% output error
3. Delta-rule recurrence holds injected noise at flat plateau over 32K tokens
4. Per-token quantization cost washes out with context

**Impact:** LLM quantization, hybrid attention architectures, edge deployment.

## CAPA: Meeting Situational Awareness

**Paper:** [2609.03923] Giving LLMs the Situational Awareness to Participate in a Meeting

In online meeting delegation, LLM agents fail to recognize when to speak. Prompt-only delegates stay silent on 51.4% of absent participant's talking opportunities (AMI corpus).

**CAPA (Collaborative Agent Predictive Architecture):**
- **Perceiver:** Updates meeting state from each observed turn
- **Predictor:** Forecasts how conversation will continue
- **Controller:** Decides whether to speak and which proposition to surface
- **Generator:** Phrases contribution in participant's style
- **Recalibrator:** Updates meeting state from verdicts

**Results on 137 AMI meetings:**
- Silence rate: 51.4% → **2.5%**
- Credited recovery: 26.1 → **52.2**
- Hallucination: **0.6%**

Mechanism ablations identify meeting state as the lever that closes the recognition gap — raw-context scaling alone does not.

**Impact:** Multi-agent collaboration, situational awareness, meeting AI assistants.

## STAIR: Structure Aware Information Retriever

**Paper:** [2609.03874] STAIR: A novel dataset and LLM based retriever for document structure augmentation

RAG still suffers from "lost in the middle" problem. Current retrievers chunk by length, throwing away rich semantic global structure (e.g., Table of Contents).

**STAIR:** Empowers an LLM to exploit global structure (ToC) to efficiently store and retrieve information.

**SearchTome benchmark:** 18 books across 6 diverse domains.

**Recall@1 results:**
- STAIR: **82.6%**
- DSI: 76.9%
- BM25: 59.5%
- DPR: 68.7%
- Mistral (out-of-the-box): 13.8%

Hallucination rate: <0.05%.

**Impact:** RAG improvement, document structure utilization, information retrieval.

## Proactive Service Agents

**Paper:** [2609.03727] Proactive Service Agents: A Unified Decision Framework, Methods, and Evaluation

Most systems take explicit user instruction as fixed starting point. Proactive service moves decision upstream: infer service opportunities from incomplete environmental and user signals.

**Four action options:** Silent, Ask, Assist, Act

**Costs to account for:** interruption, misunderstanding, overreach, privacy.

**Formulation:** Partially observable sequential decision process constrained by authorization and risk.

**Decision pipeline:** State and need estimation → Intervention gating → Action construction → Feedback adaptation

**Impact:** Agent proactive decision-making, human-agent collaboration, agent planning.
