servers: changes for clients mcp-server-fetch , mcp-server-git and mcp-server-time have no CHANGELOG, so here is what changes for a client in 2026.10.19 . They are now built on the MCP Python SDK's high-level MCPServer ( #5175 ). Unknown tool: a JSON-RPC -32602 error ( Unknown tool: &lt;name&gt; ) in both protocol eras, as the spec requires. It used to be an isError result. Tool errors read Error executing tool &lt;name&gt;: &lt;message&gt; . Argument-validation errors now use pydantic's wording. Both are still isError results. Capabilities: each server now advertises prompts and resources capabilities (with listChanged: false ). fetch's fetch prompt is the only entry in those lists. time: get_current_time and convert_time declare an outputSchema and return structuredContent .
